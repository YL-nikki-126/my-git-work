# Python 图片编辑器

## 项目介绍
1. **程序做什么**：基于 Python 和 OpenCV 的命令行图片处理工具。
2. **支持哪些功能**：
   - 读取信息：文件名、格式、宽高、颜色模式、文件大小（保留2位小数）。
   - 图片编辑：缩放、裁剪、旋转、翻转、灰度化、格式转换。
   - 通用保护：防覆盖原图、透明 PNG 转 JPG、异常防崩溃处理。
3. **程序形式**：命令行程序（CLI）。

## 环境配置
1. **Python 版本**：Python 3.8 及以上。
2. **依赖安装**：
   ```bash
   pip install opencv-python numpy
