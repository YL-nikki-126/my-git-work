# Python 图片编辑器

## 项目介绍
1. **程序做什么**：基于 Python 和 OpenCV 的命令行图片处理工具。
2. **支持哪些功能**：
   - 读取信息：文件名、格式、宽高、颜色模式、文件大小（保留2位小数）。
   - 图片编辑：缩放、裁剪、旋转、翻转、灰度化、格式转换。
   - 通用保护：防覆盖原图、透明 PNG 转 JPG、异常防崩溃处理。
3. **程序形式**：命令行程序（CLI）。

## 环境配置
1. **Python 版本**：Python 3.8 及以上。
2. **依赖安装**：`pip install opencv-python numpy`
3. **推荐使用 uv 管理环境**：项目已提供 `pyproject.toml`，可直接使用 `uv run main.py` 运行。

## 运行方式
1. **启动程序**：在终端中输入 `python3 main.py`

   **【读取图片信息】**
   - **命令**：启动后，输入图片路径，例如 `photo.jpeg` 并回车。

   **【缩放功能】**
   - **命令**：在主菜单输入 `1`。根据提示输入目标宽度（如 `800`），目标高度直接留空回车。
   - **预期输出**：`缩放完成！当前分辨率: 800 x 450`

   **【裁剪功能】**
   - **命令**：在主菜单输入 `2`。依次输入左、上、右、下坐标，例如 `100`、`100`、`500`、`500`。
   - **预期输出**：`裁剪完成！当前分辨率: 400 x 400`

   - **命令**：在主菜单输入 `3`。选择旋转角度（如输入 `1` 表示 90 度）。
   - **预期输出**：` 旋转完成！`

   - **命令**：在主菜单输入 `4`。选择翻转方式（如输入 `1` 表示水平翻转）。
   - **预期输出**：` 翻转完成！`

   - **命令**：在主菜单输入 `5`。
   - **预期输出**：`已转换为灰度图！`
